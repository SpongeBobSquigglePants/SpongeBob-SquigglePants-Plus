Want to see how the game's made? Here be the tools for diggin' through its treasure chest of files!

VolExtractor

Almost everything in SpongeBob SquigglePants is packed into .vol archives: the pictures, animations, text, fonts and sounds. VolExtractor unpacks them and turns what's inside into files you can open.

In the gameWhat you get
.image, .texture, .tplPNG, with transparency
.animA PNG for each frame, and an animated GIF
.textA spreadsheet (CSV) with a column for each language
.fontA PNG sheet of every letter, and a CSV of their sizes
.waveWAV
.arcUnpacked, with what's inside converted too

Every file is also saved exactly as it was stored, so nothing is left out.

Made for SpongeBob SquigglePants on the Wii. Other games built with WayForward's engine, EngineBlack, may use some of the same formats, but they haven't been tested. Not all of them use .vol archives: Batman: The Brave and the Bold - The Videogame on the Wii doesn't, for one.

How to Use It

  1. Get Python.Install Python 3 (on Windows, tick Add python.exe to PATH). VolExtractor installs the one extra package it needs the first time.
  2. Copy the game's archives.In Dolphin, right-click the game, choose Properties, then Filesystem, and extract the .vol files into the VolExtractor folder.
  3. Run it.Double-click extract_all.bat (Windows) or run extract_all.sh (Mac or Linux). You can also drag files or folders onto extract_all.bat.
  4. Look inside.Each archive gets a _extracted folder next to it, with raw (the files as stored) and converted (the files you can open).
No game files are included. VolExtractor only reads the copy of the game you already own.
